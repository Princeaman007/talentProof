🔍 Environment Variables Check

Cette page affiche les variables d'environnement compilées dans le build Vite.

Note: Les variables Vite sont injectées au moment du BUILD.

Si vous voyez "undefined" ou "localhost", vous devez:

  1. Vérifier que les variables sont dans Settings → Environment sur Render
  2. Faire un "Manual Deploy" pour rebuilder avec les nouvelles variables
